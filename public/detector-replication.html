The run the averages missed

For Kapton run 62, the heater fit predicted 0.42 V and the previous Kapton mean predicted 0.65 V. The detector measured a 6.07 V drop. Its preheat median was −0.183411 V. Cell W344 reached −6.253970 V, 160 seconds after heater onset. The archived optical readings leave the cause unresolved.

Twelve of the 18 peaks fall between 6.06 and 6.09 V. A narrow range of large instrument signals can make a material average accurate while obscuring differences in smoke concentration. The investigators selected heater targets separately for each material. Calibrated particle size, concentration and instrument response would help separate those effects. How the runs were selected

Outside runs 73–86, 26 base-ID condition rows had 8.1 cm/s inlet flow, 60 s nominal heating, 11 s primary aging and 8 s primary mixing. Run 51 lacked a matching analyzed workbook. Two rows assigned run 57 to different materials. This left 23 distinct workbooks for review.

Run 63 lacked a matched heater onset. Run 88 had a four-second gap, exceeding the two-second limit. Of the 21 usable runs, NASA identified run 90 as a reburn of training sample 85, and FIRST FIRE had previously opened the traces for 92 and 93. We included those three only in the sensitivity analysis. Across all 21, the material mean’s error was 0.55 V, the heater fit’s was 1.37 V, and the pooled mean’s was 2.43 V.

Four primary runs had higher run numbers than the training block and fourteen had lower ones. The material mean had lower error in both groups. The team wrote the eligibility and scoring rules before extracting the additional outcomes. This retrospective plan carries no third-party timestamp. Every run used the same ISS detector campaign. Independent teams, other instruments and new materials remain to be tested.

Run the checks

Save the four downloads together. Python 3.10 or later can verify the model, recalculate each prediction and recompute each error from the published observations.

python3 detector-replication.py

To check the original native cells, save the NASA condition table and NASA file census snapshot in a folder named raw, and run the following commands.

python3 -m pip install xlrd==2.0.2
python3 detector-replication.py --raw raw --cache workbooks --download

The full check downloads 23 versioned workbooks and verifies their SHA-256 digests. It repeats the eligibility and timing checks, including records excluded from scoring.
