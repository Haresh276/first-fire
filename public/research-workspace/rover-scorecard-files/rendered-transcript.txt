Q2 — Causality and experimental design

No causal conclusion is justified. Airflow direction changed, but S2 burned the specimen remaining after S1. The sequential design confounds direction with specimen condition and test order.

A fair next experiment would use fresh, identical specimens, comparable atmospheric and airflow conditions, randomized direction order across independent trials, and repeated measurements.

W2 — Runnable JavaScript validator
JavaScript

function valid(rateMmS, timeS, travelCm) {
  if (
    !Number.isFinite(rateMmS) ||
    !Number.isFinite(timeS) ||
    !Number.isFinite(travelCm)
  ) {
    return false;
  }

  if (rateMmS < 0 || timeS < 0 || travelCm < 0) {
    return false;
  }

  const expectedCm = rateMmS * timeS / 10;

  // This validator applies only before strip-end clipping.
  if (!Number.isFinite(expectedCm) || expectedCm > 40) {
    return false;
  }

  return Math.abs(travelCm - expectedCm) <= 0.000001;
}

// Tests
console.log(valid(1.8, 37, 6.66)); // true
console.log(valid(1.3, 37, 4.81)); // true
console.log(valid(1.8, 37, 6.67)); // false


The validator uses the stipulated rate law, rejects nonfinite and negative inputs, excludes distances requiring strip-end clipping, and applies the specified absolute tolerance of 0.000001 cm.
