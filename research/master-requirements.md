# Implementation of the interim master document

Team Code Blooded’s 101-page Master Document 1.0 defines the scientific claims, instrument designs, acceptance tests and competition handoff. Use the [Field guide](../dist/index.html#field-guide) to run the instruments. Use the [review record](signoff.md) to see which statements still require external evidence.

## What still decides the scientific result

The signed forecast can be scored only after an attributable outcome identifies a valid burn. Longer-term habitat credibility needs independently measured gas, temperature, detector and flame-front traces. Routing reached its specified threshold on the third independent set. Confidence calibration still missed its target. A real counterbalanced participant study is required to estimate any advantage over ordinary search. These distinctions apply to the published judge materials as well as to the interactive tools.
