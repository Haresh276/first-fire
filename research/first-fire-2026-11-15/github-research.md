# What the public repositories add to FIRST FIRE

15 November 2026 · NASA Space Apps, Flame in Freefall

## Three results the team can show

**A detector result that a reader can reproduce.** HALO identified a NASA workbook missing from FIRST FIRE's normalized detector evidence. I downloaded NASA's PSI-101 study version 4, file version 1, independently. It is byte-identical to HALO's 4,061,669-byte copy, SHA-256 `6d3a539ccf425b1fa8edc19cc75d828f57d650c7ce734d4e7aa686fea9593218`. On the **Material Sort** sheet, keep rows with flight code 1 or 2 in column A. The resulting 154 rows are unique on (flight code A, SAME number G). Using the test ID in E with flight code leaves a duplicate 4K. Column AW is ISS detector scatter in volts. Each denominator below counts only numeric AW values. [NASA versioned workbook](https://psi.nasa.gov/geode-py/ws/studies/PSI-101/download?file=PSI-101_Analyzed+Data_SAME%2C+SAME-R_Results.xlsx&version=1&studyVersion=4) · [NASA dataset DOI](https://doi.org/10.60555/2np7-jv14) · [HALO’s analysis](https://github.com/MaanavKrishna/HALO-Habitat-Assessment-from-Low-Gravity-Observations/blob/214fe39815f9fb2c43c06d5d2d4764917adcb935/pipeline/halo_pipeline/detector.py)

A useful next test would compare synchronized sensor traces at controlled aging and inlet velocity. Keep this published example out of a future independent question set. **An external check on the normalized archive.** R-Nour's public answer key covers 881 physical rows across eight PSI files. I checked that each file's lines matched FIRST FIRE's raw file after decoding and line-ending normalization, then joined by source file and 1-based line. FIRST FIRE had normalized records for 674. All 207 unmatched entries were PSI-10 normal Flame Design rows, which are present in the raw archive. Across the 274 joined FLEX rows, oxygen, absolute pressure and burn duration gave 813 mutually numeric agreements within R-Nour's tolerances (0.05 percentage points, greater of 1% or 0.02 psi, and 0.05 s), seven jointly missing values, and two NASA approximate durations that FIRST FIRE retains with notes and the key leaves blank. Agreement measures how two parsers represent shared NASA input. The shared source prevents this from testing predictive validity. [R-Nour’s published key](https://github.com/R-Nour/Flame-Atlas/blob/b54ebae7eed48a55aa17b5f974ce381d5421d43f/data/answer_key.json) · [Peer scoring code](https://github.com/R-Nour/Flame-Atlas/blob/b54ebae7eed48a55aa17b5f974ce381d5421d43f/tools/check.py) · [NASA FLEX dataset](https://doi.org/10.60555/mbq8-0451)

Two disagreements make better tests than a headline percentage. In BASS-II the peer key expects airflow values for 121 rows where FIRST FIRE leaves velocity unknown. The NASA CSV column is labelled *Air display* without velocity units. Preserve the display alongside any separately documented calibration. In the normal CFI-G table, FIRST FIRE has numeric burn durations on 43 rows where the key has null, including explicit zeros on unsuccessful ignitions. A test should distinguish a reported zero, an unreported measurement, an approximate value, and a failed ignition. R-Nour’s scorer iterates expected rows and overwrites duplicates keyed by file and line, so extra output rows or duplicate predictions can escape its reported accuracy. Include false extra rows and duplicate IDs in FIRST FIRE's conversion checks. [NASA BASS-II table](https://doi.org/10.60555/4qc4-de67) · [Peer extractor and prompts](https://github.com/R-Nour/Flame-Atlas/blob/b54ebae7eed48a55aa17b5f974ce381d5421d43f/tools/extract.py)

**Show which experimental choice survives a changed assumption.** MARGIN repeats its coverage verdict across 27 combinations of oxygen, pressure and airflow distance scales and counts how often even the best match is partial. Its gate treats a reported flammability limit separately from a directly tested condition and excludes planned experiments. FIRST FIRE already locks a FLEX comparison before revealing the outcome. I ran the shipped matcher on archived orbital methanol runs at 15% versus 21% O₂, 14.7 psia target, no CO₂ or helium. At a 0.05 mm diameter tolerance only runs 66↔6 qualify, giving −3.3 s for high-minus-low oxygen burn duration. At 0.10, 0.20 and the default 0.35 mm, the same three pairs (65↔202, 66↔6, 67↔34) give +1.6 s. At 0.70 mm the matcher substitutes 66↔33 and the mean becomes +2.2 s. Requiring the same test day gives zero pairs at all five tolerances. That sign change is a reproducible example of how a comparison depends on eligibility choices. It does not estimate a causal oxygen effect. Show both sample IDs and the denominator when changing the tolerance. [MARGIN’s robustness calculation](https://github.com/ADAI-ALEX/margin/blob/5c5afba01aafb1280d7b199fb6f7225d1646c40e/lib/engine/robustness.ts) · [MARGIN’s eligibility gate](https://github.com/ADAI-ALEX/margin/blob/5c5afba01aafb1280d7b199fb6f7225d1646c40e/lib/engine/gate.ts) · [FIRST FIRE’s existing paired analysis](../../research/advanced-methods.md)

## How to reproduce the search

The event-wide search used `"NASA Space Apps" "2026" in:name,description,readme` with repository creation dates from January 1 through November 15 UTC. Eleven disjoint date/time partitions, each under the search API's 1,000-result retrieval ceiling, returned 5,870 unique owner/repository pairs across 65 pages. The initial unpartitioned count was 5,862. Search results changed during retrieval, including within individual partitions. All pages reported a complete query response. The event was under way. A repository matching these terms may be an organizer site, collection, unrelated project, duplicate team effort or project from another challenge. ### What the wider search found

For all 5,870 event search candidates I checked the default branch for a root README. I retrieved and keyword-screened 5,623 complete README texts, including 30 found under an alternate root filename. For the remaining 247, no root README text was returned. I matched challenge-phrase variants, combustion/flame or fire-safety language near microgravity terms, and experiment names paired with spacecraft-fire or PSI language. The event CSV records the Git blob hash for every retrieved text. The 336 keyword hits include 332 entries already in the combined challenge inventory and four further research leads. This English-language screen can miss projects documented elsewhere or described in another language. [Event CSV with screening results](event-repositories.csv)
