## What changed in FIRST FIRE

**A habitat can match three individual ranges without matching a single experiment.** Imagine that one test ran at 34% oxygen and 14.7 psia, and another at 21% and 8.2 psia. The ranges include 34% and 8.2 psia, yet neither run tested them together. Habitat Compass now counts records that match gravity, ambient oxygen and absolute pressure **in the same observation**. It shows how many rows lacked a required measurement and lets the reader open a match. Its ±0.02 g, ±1 oxygen percentage point and ±0.5 psia tolerances are search choices. Ranking remains available when the target has zero matching rows. [Try the Compass](#compass) · [Investigation-level coverage calculation reviewed](https://github.com/AllMites/taomoeba-project/blob/83d91177ed5517468547bcc659689793c2df402a/scripts/rag/brief_facts.py#L61-L83)

**A correct number can still support the wrong answer.** A LUCI source reports about 45 seconds longer. Replacing seconds with minutes preserves the digits while increasing the claimed difference sixtyfold. FIRST FIRE now demonstrates this error in its public Referee log. Its new regression cases also exercise the wrong specimen, detector, source page, sign and direction. The positive unit test converts 0.75 minutes to 45 seconds before comparing the quantity. Source authentication and scientific interpretation are separate checks. [Open the public errors](#referee?view=errors) · [Numeric validation implementation reviewed](https://github.com/prattaybanik03/flamebound-flame-in-freefall/blob/a7adbbeb05f3c4cd6af3b7141c91e8ed09d8d9ac/web/src/lib/explain.ts#L64-L86) · [Digit and citation regression cases reviewed](https://github.com/MohammedAnasuddinZaid/NASA-hackathon/blob/2d9d4e7801b7cf521b8e3a424de5d65b008d280b/backend/tests/test_grounding.py#L5-L28)

**One burn can generate several observations.** Splitting rows at random can put a burn’s start in training and its end in testing. FlameLens keeps these paired observations together during evaluation. FIRST FIRE’s next validation against measured cabin traces should hold out whole physical runs. For the human blind test, select comparable records using conditions available before ignition and reveal outcomes after selection. A classifier tested on synthetic trajectories still needs independent physical measurements. [FlameLens grouped validation](https://github.com/ManmathX/NasaProject2026/blob/86a92ddca21170431c06d848aac668111c2bc770/src/flamelens/spread.py#L65-L81) · [FIRST FIRE blind-test protocol](evaluation.md) · [Current physics validation](world-model.md)

## Detailed implementation and test readings

Sixteen focused readings follow. They inspect source and test logic for assumptions that change which scientific conclusions can be drawn. The linked revisions make the findings reproducible even when a project changes.

### Forecasts and simulations

#### ManmathX/NasaProject2026

A SIBAL classifier creates 36 binary observations from 23 physical tests, preserving source-page and oxygen quality flags. Each test’s start and end rows stay together during leave-one-test-out evaluation. A regression test requires low-coverage inputs to return no probability. Its pooled negative class includes failure to ignite, blowoff and quench, which limits endpoint-specific interpretation. [Label conventions](https://github.com/ManmathX/NasaProject2026/blob/86a92ddca21170431c06d848aac668111c2bc770/src/flamelens/spread.py#L36-L46) · [Grouped fitting](https://github.com/ManmathX/NasaProject2026/blob/86a92ddca21170431c06d848aac668111c2bc770/src/flamelens/spread.py#L65-L81) · [Source and transfer assertions](https://github.com/ManmathX/NasaProject2026/blob/86a92ddca21170431c06d848aac668111c2bc770/tests/test_spread.py#L19-L45)

#### badr5556/FlameMargin

For opposed-flow PMMA slabs, 39 tracked rates from 18 tests support a conditional spread-speed fit. Within each test, the table supplies only initial and final O₂. The program refits using each value, reports leave-one-test-out residuals against a training-mean baseline, and withholds a speed beyond the oxygen, thickness or flow ranges. The residual interval is empirical. A new geometry or a lunar atmosphere would require its own evidence. [Measurement limitations](https://github.com/badr5556/FlameMargin/blob/383a3bb4379aa7e45cdae942e684a610b82a311e/src/spread_rate.py#L1-L15) · [Sensitivity and interval](https://github.com/badr5556/FlameMargin/blob/383a3bb4379aa7e45cdae942e684a610b82a311e/src/spread_rate.py#L78-L99) · [Scope checks](https://github.com/badr5556/FlameMargin/blob/383a3bb4379aa7e45cdae942e684a610b82a311e/src/spread_rate.py#L120-L144) · [Transfer regression test](https://github.com/badr5556/FlameMargin/blob/383a3bb4379aa7e45cdae942e684a610b82a311e/tests/test_engine.py#L154-L163)

#### ruska51/prometheus-0g

For FLEX droplets the code compares theory to measurements by fuel, diluent and pressure class, converts m²/s to mm²/s and computes a median measured-to-modeled ratio. Three different definitions of extinction treat disrupted runs differently. A regression test fixes the definitions and another recomputes grouped model comparisons. An error or label definition measured on droplets belongs with that endpoint and material. [Parity and unit conversion](https://github.com/ruska51/prometheus-0g/blob/d9d13bd810576cb5a6581fff75b499b5efd41a9c/scripts/physics_vs_data.py#L31-L59) · [Alternate endpoints](https://github.com/ruska51/prometheus-0g/blob/d9d13bd810576cb5a6581fff75b499b5efd41a9c/src/fif/validation/label_sensitivity.py#L29-L42) · [Label definitions and grouped model check](https://github.com/ruska51/prometheus-0g/blob/d9d13bd810576cb5a6581fff75b499b5efd41a9c/tests/test_validation.py#L73-L104)

#### Siew22/Nasa-Space-Apps-Sarawak

An educational parcel model derives reduced gravity and the buoyancy/ventilation velocity ratio. It marks an undefined ratio when imposed flow is zero. Tests isolate the force and velocity at zero gravity and compare Earth, Mars and Moon with the remaining controls held fixed. A separate fitting pipeline uses grouped folds, and its test deliberately contaminates a split to ensure the audit catches leakage. The schematic scalar field is not an observed or calibrated flame image. [Parcel model and domain](https://github.com/Siew22/Nasa-Space-Apps-Sarawak/blob/9c6c8848086c6680fc10f7a3e14e6d1db3d8b061/app/services/simulation_service.py#L23-L60) · [Zero and partial gravity checks](https://github.com/Siew22/Nasa-Space-Apps-Sarawak/blob/9c6c8848086c6680fc10f7a3e14e6d1db3d8b061/tests/test_simulation_physics_limits.py#L15-L63) · [Model selection](https://github.com/Siew22/Nasa-Space-Apps-Sarawak/blob/9c6c8848086c6680fc10f7a3e14e6d1db3d8b061/src/train_flex_models.py#L48-L76) · [Injected leakage](https://github.com/Siew22/Nasa-Space-Apps-Sarawak/blob/9c6c8848086c6680fc10f7a3e14e6d1db3d8b061/tests/test_group_cv.py#L55-L70)

#### HAILVince/nasa_space_apps_2026

This model interpolates material-specific ground oxygen thresholds in log pressure. It then applies a common gravity shift, low-flow penalty and temperature correction. A test checks that the interpolator reproduces its own input points. Another verifies the chosen three-percentage-point shift. Both are useful implementation checks. Neither supplies a new lunar measurement nor an independently measured lunar prediction error. [Interpolation and corrections](https://github.com/HAILVince/nasa_space_apps_2026/blob/e938b2284990496f489157c2cba8583172c4eda2/blackfox/physics/fire.py#L191-L229) · [Input anchors and assumed lunar ordering](https://github.com/HAILVince/nasa_space_apps_2026/blob/e938b2284990496f489157c2cba8583172c4eda2/tests/simulation/test_fire.py#L9-L35)

#### Zucloak/Ignimetheus

The comparison score exposes distances for material, oxygen, gravity, pressure, flow and geometry. Its nearest-neighbor score also penalizes disagreement between the simulated outcome and the observed spread rate or burn length. Selecting benchmarks this way would favor matching outcomes in a blind test. Its data tests explicitly keep standards-based pass/fail criteria out of measured spread rates and preserve the Nomex starter-piece note. [Input terms](https://github.com/Zucloak/Ignimetheus/blob/72f8e85acdd059d18c271df54fb6a923b9bc6e57/src/engine/thermoCore.ts#L1728-L1747) · [Outcome-dependent selection](https://github.com/Zucloak/Ignimetheus/blob/72f8e85acdd059d18c271df54fb6a923b9bc6e57/src/engine/thermoCore.ts#L1749-L1775) · [Criterion-only record](https://github.com/Zucloak/Ignimetheus/blob/72f8e85acdd059d18c271df54fb6a923b9bc6e57/src/engine/thermoCore.test.ts#L733-L745) · [Starter-piece assertion](https://github.com/Zucloak/Ignimetheus/blob/72f8e85acdd059d18c271df54fb6a923b9bc6e57/src/engine/thermoCore.test.ts#L776-L783)

#### baonamv200/Bebo-ZeroG-X

The Rust model combines forced and buoyant velocities in quadrature and adds low-flow quench, high-flow blowoff and pressure corrections to an oxygen threshold. The boundary tests check finite sweeps and internal thresholds. One failure mode appears directly in the scoring function: a non-finite O₂ input or effective threshold returns the same zero-score “Safe” category as a finite below-threshold input. Scientific dashboards should distinguish missing input from measured low risk. [Threshold function](https://github.com/baonamv200/Bebo-ZeroG-X/blob/79b0b47b6c9a90cd784ec26994f0920aa2a5da17/src/physics.rs#L54-L77) · [Invalid values become safe](https://github.com/baonamv200/Bebo-ZeroG-X/blob/79b0b47b6c9a90cd784ec26994f0920aa2a5da17/src/physics.rs#L130-L143) · [Boundary sweep test](https://github.com/baonamv200/Bebo-ZeroG-X/blob/79b0b47b6c9a90cd784ec26994f0920aa2a5da17/tests/test_extinction_curves.rs#L9-L32)

#### maxtronh/NASA-SPACE-APP-2026

The deployed surrogate class synthesizes a diameter trajectory using fuel lookup constants, oxygen and pressure scaling, and an explicit regime threshold. An unknown fuel falls back to heptane inside the predictor. Its output names a computed condition “cool_flame_observed.” The inspected inference method has no trained network weights. Its test checks bounds and expected phases, which cannot establish agreement with a held-out flight measurement. [Lookup, formula and thresholds](https://github.com/maxtronh/NASA-SPACE-APP-2026/blob/8948a85f934054e2bda272a9f970a85322a4d38a/backend/app/kinetics/pinn_surrogate.py#L97-L139) · [Synthetic regime reported as observed](https://github.com/maxtronh/NASA-SPACE-APP-2026/blob/8948a85f934054e2bda272a9f970a85322a4d38a/backend/app/kinetics/pinn_surrogate.py#L199-L211) · [Expected phases and bounds](https://github.com/maxtronh/NASA-SPACE-APP-2026/blob/8948a85f934054e2bda272a9f970a85322a4d38a/backend/tests/test_pinn_surrogate.py#L17-L65)
