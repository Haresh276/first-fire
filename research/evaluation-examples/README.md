# Evaluator file examples

Use participant.example.json for a timed rehearsal and key.example.json for masked grading. The questions were written by the implementer and are visible with this source tree. The example study ID is reserved for practice, and the analyst refuses to count practice toward an evaluation. To test the analyst workflow with fabricated submissions, use the automated tests. To measure people, use independently authored files with a new study ID and follow ../evaluation.md. Neither real participant data nor real unpublished keys belong in this directory.
