    Run a 12-minute session

    1. First two minutes. Invite a researcher, engineer or instructor responsible for a real testing decision. Agree on one safety question and a shareable context. The reviewer records the first decision before seeing the evidence and saves a starting record.
    2. Next six minutes. Let the reviewer open the ranked studies and original sources without coaching. Ask for the exact observation that informed the second decision. Capture unchanged plans, deferrals and challenges alongside changes.
    3. Last four minutes. Record any actual use with a dated document or session reference, choose sharing permission, and download the decision. File dates are local device times. Ask permission before identifying a group or publishing its words.
    4. Independent reuse. Send another group only the task invitation. Ask them to repeat the 12-minute exercise and return their decision file with a source or counterexample. Record the second group’s location with permission if geographic reach is relevant.
    5. Close the loop. Open the originating group’s completed decision, add the second decision, and document the response to its challenge. Return the exchange file to both groups. A facilitator should keep private records local, follow the narrower sharing permission, and verify claimed real-world use with its owner.
